## 🚀 Projetos em destaque

### 📊 Auditoria de Planilhas

Aplicativo desktop para Windows que compara planilhas Excel e auxilia
na revisão de traduções entre inglês e português. Permite analisar
diferenças, aplicar correções individuais ou em massa, retomar sessões
de trabalho e exportar relatórios e cópias corrigidas.

O processamento é local, sem enviar o conteúdo das planilhas à internet.

**Tecnologias:** Python · Electron · JavaScript

<a href="https://github.com/Flerno14/AuditoriaPlanilhas">

</a>

### 💾 Automação de Backup

Script para Windows que automatiza a cópia de arquivos entre pastas
com o Robocopy. Utiliza monitoramento de alterações para atualizar
a pasta de destino, incluindo subdiretórios e pastas vazias,
mantendo uma cópia de apoio dos arquivos.

**Tecnologias:** Windows Batch · Robocopy

<a href="https://github.com/Flerno14/Backup-constante">
  <img src="https://img.shields.io/badge/Ver_projeto-0D1117?style=for-the-badge&logo=github&logoColor=38BDF8" alt="Ver Automação de Backup" />
</a>

---

### 📦 i-Stock Manager

Projeto acadêmico colaborativo em desenvolvimento para o gerenciamento
de estoque de pastilhas industriais da DDA Metalúrgica.

A proposta é substituir o controle por planilhas e registros manuais
por uma aplicação web que centralize entradas, saídas, níveis mínimos
e histórico de movimentações, apoiando o planejamento de reposições.

**Backend e banco de dados previstos:** Java · Spring Boot · MySQL

<a href="https://github.com/Cadu-f12/i-Stock-Manager">
  <img src="https://img.shields.io/badge/Ver_projeto-0D1117?style=for-the-badge&logo=github&logoColor=38BDF8" alt="Ver i-Stock Manager" />
</a>

---

### 💜 Mina Tech

Aplicação web para a iniciativa MinaTech, voltada à ampliação de
oportunidades para mulheres em tecnologia e engenharia.

Reúne informações sobre a iniciativa, programação, organizações
participantes e dúvidas frequentes, além de páginas de inscrição,
contato e cadastro de voluntários.

**Tecnologias:** React · JavaScript · Vite · Bootstrap · Firebase
